## Overview

The public site and the game share one Next.js app. Beers, posts and the quiz are typed data in the repo; players and their progress live in Supabase.

## Technical Implementation

### Auth

Supabase Auth with row-level security. The session JWT is verified locally, so most requests never reach the auth server, and a short abort keeps the site usable when Supabase is slow.

### Game

Exploration, combat, stamina, allies and a weekly ranking. Combat is settled on the server, and its odds are covered by simulation tests.

### Conversion

There is no store: every beer ends in a call to order by Instagram message.

## Features

- Beer catalog with a page per beer
- Quiz that assigns each visitor a path
- Blog with category filters
- RPG: fortress dashboard, exploration, inventory, allies and weekly ranking
- Code and QR redemption for codes printed on bottles
- Welcome emails through Resend
