## Overview

PerfectApp connects field sales reps, coordinators, administrators and retail clients. Each role has a private area behind a public landing page.

## Technical Implementation

### Access Control

Next.js Pages Router with NextAuth.js credential sessions. Each protected page checks the role in `getServerSideProps` before loading data; API routes do too.

### Multi-Company Data

Each user belongs to a company, which scopes queries and configuration (SKUs, competitors, promotions) within one deployment.

### Visit Workflow

Reps record competitor prices with photos, inventory, the purchase order or reason for no purchase, and communication material execution. Photos go to Vercel Blob; submitting stores the visit and a pending order, and a summary is emailed.

### Loyalty Points

Points are valued per client tier and SKU. Admins credit them on validation and can double them for clients over their monthly quota.

## Features

- Rep dashboard with monthly quota progress
- Coordinator view: quota per rep and purchasing clients
- Client portal with points balance, promotional banners and rewards catalog
- Admin panel: order approval, prospect validation, monthly promotions and messages to reps
