## Overview

Sonámbulo is a creative studio working in branding, route-to-market strategy and digital products. The site is a Spanish one-page home plus a page per case study.

## Technical Implementation

### Scroll sequence
On desktop, the About section pins a sticky viewport and maps scroll progress to the opacity, position, scale and rotation of each text block. Lenis smooths wheel scrolling.

### Input-aware cards
Capability and process cards expand on hover with a fine pointer and toggle on tap on touch devices. Both respond to Enter and Space and expose `aria-expanded`.

### Case studies
Routes under `/portfolio/[slug]` read from a JSON file and build metadata and Open Graph images per client.

### Cursor and motion
A custom cursor follows the pointer with spring physics and changes state over links, buttons and images. CSS animations stop under `prefers-reduced-motion`.

## Features

- Sticky scroll About sequence on desktop
- Expandable capability and process cards
- Case study pages with insight cards and image carousel
- Custom animated cursor
- Smooth scrolling
