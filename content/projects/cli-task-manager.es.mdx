## Resumen

Aplicación de línea de comandos en Python que guarda una lista de tareas en `tasks.json`. El archivo se escribe en el directorio de trabajo tras cada cambio.

## Implementación Técnica

### Modelo de datos
Campos: título, categoría opcional, UUID, fecha de creación, estado de completado. Las actualizaciones usan `dataclasses.replace`.

### Almacenamiento
Si el archivo no existe se carga una lista vacía, así que la primera ejecución no requiere configuración.

### CLI
Cada subcomando de `argparse` va a un handler que carga, aplica el cambio y guarda.

## Funcionalidad

- `add "<título>" --category <nombre>` crea una tarea; la categoría es opcional
- `list` muestra estado (`[X]` / `[ ]`), título, fecha, categoría e ID
- `complete <id>` marca una tarea como completada
- `delete <id>` elimina una tarea
