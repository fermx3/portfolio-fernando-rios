## Resumen

El dashboard en Streamlit sube un CSV con columnas `date` y `sales` y muestra el histórico, el pronóstico y las métricas de error. Es un cliente de una API REST que entrena y sirve el modelo.

## Implementación Técnica

### Procesamiento de Datos

`DataProcessor` verifica las columnas requeridas, rechaza series cortas, negativas o constantes, rellena huecos y descarta outliers a más de tres desviaciones estándar.

### Modelo

`DemandForecaster` envuelve Prophet con estacionalidad aditiva semanal y anual. Entrena con todo salvo los últimos 30 días, evalúa sobre esa cola y genera fechas futuras con límites del 95%.

### API

FastAPI expone endpoints de salud, carga de CSV y entrenamiento, pronóstico y estadísticas del dataset. Los datos inválidos devuelven un 400 con la validación que falló.

### Despliegue

Cloud Build construye la imagen, la sube a Container Registry y la despliega en Cloud Run.

## Funcionalidad

- Pestañas Historical, Forecast y Metrics con gráficas interactivas de Plotly
- Slider de horizonte de pronóstico y toggle de intervalos de confianza
- Mensajes de validación ante datos mal formados o insuficientes
- Notebook de análisis exploratorio
