## Overview

This site. It presents Fer's projects in English and Spanish and includes a chat assistant that answers questions about them and can forward a visitor's contact details.

## Technical Implementation

### Content

Projects live in `content/projects/` as `<slug>.mdx` and `<slug>.es.mdx`. Gray Matter extracts the frontmatter, Zod validates it, and `markdown-it` renders the body; the slug comes from the file name. A CI script checks images, EN/ES parity and tag rules.

### Internationalization

next-intl serves `/en` and `/es` from one component tree. Sitemap, canonical URLs, `hreflang`, Open Graph images and JSON-LD are generated per locale.

### Assistant

A Node.js route streams Claude responses. The system prompt, cached as a stable prefix, holds every project plus the profile. A contact tool sends visitor details through Resend; if a service is missing, the assistant degrades to the next fallback.

## Features

- Search with category and tag filters in the active language
- Gallery with lightbox, grouped into web and mobile screenshots
- Light/dark theme following the system preference
- Scroll-triggered animations with Framer Motion
