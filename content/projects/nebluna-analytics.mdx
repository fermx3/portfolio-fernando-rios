## Overview

The Streamlit dashboard uploads a CSV with `date` and `sales` columns and shows the history, the forecast and the error metrics. It is a client of a REST API that trains and serves the model.

## Technical Implementation

### Data Processing

`DataProcessor` checks the required columns, rejects short, negative or constant series, fills gaps and drops outliers beyond three standard deviations.

### Model

`DemandForecaster` wraps Prophet with additive weekly and yearly seasonality. It trains on all but the last 30 days, scores on that tail and generates future dates with 95% bounds.

### API

FastAPI exposes health, CSV upload and training, forecast and dataset statistics endpoints. Invalid data returns a 400 with the failed check.

## Features

- Historical, Forecast and Metrics tabs with interactive Plotly charts
- Forecast horizon slider and confidence interval toggle
- Validation messages for malformed or insufficient data
- Exploratory analysis notebook
