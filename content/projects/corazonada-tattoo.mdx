## Overview

The site is in Spanish only and has no contact form: booking requests go straight to the studio's WhatsApp.

## Technical Implementation

### Data layer
Server Actions query the artist and post collections. Artist and post routes are generated with `generateStaticParams`, and unknown slugs return 404.

### Artist pages
Each profile combines a cover image, a bio card and a portfolio grid. Artists flagged as private are left out of the guest listing and served with `noindex`.

### Blog
Post HTML stored in the database is sanitized before rendering. The like counter updates through a Server Action that revalidates the post page.

## Features

- Video hero with booking call to action
- Autoplay studio carousel
- Guest artist grid and individual profile pages
- Portfolio modal with looping carousel
- Blog with featured posts and like counter
- Floating WhatsApp button
