## Overview

Classifies a coffee leaf photo as healthy or as one of four diseases.

## Technical Implementation

### Models

VGG16 and EfficientNetB0 with ImageNet weights, plus a lightweight custom CNN. Training runs in two phases, frozen base then fine-tuning, with dropout, early stopping and a learning rate chosen by dataset size. The loader detects the architecture from the saved model's layers.

### Data

Images are letterboxed to 224x224 and split per class into train, validation and test sets.

### Serving

FastAPI validates the image format, runs inference on a cached model and returns the top class plus every class probability. The API ships as a Docker image; trained models are uploaded to Google Cloud Storage.

## Features

- Image upload endpoint and health check that reports whether the model is loaded
- Separate [Streamlit app](https://github.com/fermx3/coffeedd-web) for upload and prediction
- Evaluation with confusion matrix and false-negative analysis
- Train, evaluate and predict commands through Make targets
