## Overview

Python command-line app that keeps a to-do list in `tasks.json`. The file is written to the working directory after every change.

## Technical Implementation

### Data Model
Fields: title, optional category, UUID, creation timestamp, completion flag. Updates use `dataclasses.replace`.

### Storage
A missing file loads as an empty list, so the first run needs no setup.

### CLI
Each `argparse` subcommand maps to a handler that loads, applies the change and saves.

## Features

- `add "<title>" --category <name>` creates a task; category is optional
- `list` prints status (`[X]` / `[ ]`), title, date, category and ID
- `complete <id>` marks a task as done
- `delete <id>` removes a task
