## Overview

Runs from the terminal with the log path as its only argument (`python main.py logs/sample.log`) and prints the report to standard output.

## Technical Implementation

### Parsing
`parser.py` reads the file line by line and matches `YYYY-MM-DD HH:MM:SS LEVEL message` for `INFO`, `WARNING` and `ERROR`. Lines that don't match are skipped; a missing file logs a warning and exits.

### Analysis
`analyzer.py` counts entries per level with `Counter` and ranks `ERROR` messages with `most_common()`, top 5 by default.

### Reporting
`reporter.py` prints aligned columns with f-string formatting.

## Features

- Count of entries per log level
- Top 5 most frequent error messages with occurrence count
